# 실제 수정 문장 의미 보존 라벨링 지침

`human/semantic_labels.html`을 브라우저로 열어 각 항목을 판정하고 **CSV 저장**을 누른다. 또는 `human/semantic_labels.csv`의 `human_label`, `human_reason`만 채운다. 문항·원문·수정문·문맥은 수정하지 않는다. 저장하지 않고 창을 닫으면 HTML의 선택은 사라진다.

평가 대상은 문장의 뜻이다. 더 자연스럽거나 세련된 문장인지와 구분한다. 필요한 경우 원문/수정문 문맥을 펼쳐 확인한다. 여러 문장으로 분할·병합된 경우 해당 구간 전체를 비교하고, 한쪽이 비어 있으면 정보가 추가/삭제됐는지 본다. 비식별 표시의 숨겨진 내용을 추측하지 않는다.

| 라벨 | 판정 기준 |
|---|---|
| 보존 | 사실·주장 방향·감정 강도·가능성/양태·시제·부정·수량이 유지됨. 맞춤법·조사·동일 의미의 문체 변경 포함 |
| 경미한 뉘앙스 변화 | 중심 명제는 같지만 강조·태도 등의 뉘앙스가 조금 달라짐 |
| 의미 변화 | 사실·근거·인과·주장·우선순위·감정의 뚜렷한 강도·가능성과 실제 발생의 구별·시제·부정·수량이 변하거나 추가/삭제됨 |

짧게 이유를 남긴다. 판단이 어려우면 근거와 불확실성을 이유에 적고, 비교 가능한 문맥이 전혀 부족하다면 임의로 채우지 말고 해당 항목을 알려준다. 미입력 항목을 빼고 통과율을 높이지 않으며 모든 지정 항목을 확인한 뒤 검증한다.

이 시트에는 수정 조건·모델·실행 ID·judge 판정·선정 이유가 없다. 라벨링 중에는 별도의 `private/` 자료와 judge 결과를 열지 않는다. 소스 글을 이전에 읽어 기억하는 데 따른 완전하지 않은 맹검의 한계는 남는다.

통과 판정에서는 `보존` 대 `변화` 두 범주를 쓴다. **경미한 뉘앙스 변화도 변화에 포함**한다. 실제 수정 문장에 대한 Cohen's kappa 0.6 이상이어야 하며, 규칙 변형에 대한 kappa도 별도로 0.6 이상이어야 한다. 기준은 결과를 보기 전에 고정했다. 95% 신뢰구간은 글 단위로 묶어 재표집해 보고한다. 표본은 개발용 다섯 글에서 나오므로 신뢰구간과 일반화에 한계가 있다.

오류 후보를 의도적으로 포함한 judge 검증용 표본이다. 이 50개에서 보존으로 판정된 비율을 전체 에이전트의 의미 보존율로 사용하지 않는다. 쌍대 비교의 사람 라벨링은 하지 않는다. 쌍대 비교 judge는 동일 문항의 사람 점수 차이가 큰 원문 쌍을 이용해 별도로 검증한다.
